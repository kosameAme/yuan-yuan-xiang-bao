# 鸢鸢相抱

代号鸢抽卡手账，公开分享入口由 GitHub Pages 发布。

完整网站：https://yuan-draw-journal.sassy-spool-7281.chatgpt.site

## 源码
完整源码保存在 `yuan-yuan-xiang-bao-source.zip`，解压后包含前端、账号 API、数据库迁移、依赖锁定和开发说明。源码版本：c476428820fcbb3ddb28ca44cf5b77cf31263093。

五套主题：默认白黑色、古早苹果拟物、浅蓝玻璃拟态、浅紫色、水蓝色。支持卡池统计、多游戏角色、独立账号密码和手动云端备份。

## Pages 发布
Settings → Pages → Deploy from a branch → main → / (root)。仓库根目录的 index.html 为公开分享入口，会自动打开完整网站。

GitHub Pages 只能运行静态网页，账号 API 与云端备份继续由现有后台提供。因此本入口保留完整网站功能，并不把账号数据放入公开仓库。源码包不含账号、备份和访问凭据。
